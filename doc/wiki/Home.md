# CANSLIM Analysis Wiki

This project runs a hybrid CANSLIM workflow:

1. Quantitative screening.
2. Verified qualitative enrichment.
3. Strict schema validation.
4. Final seven-criterion scoring.
5. JSON and PDF reporting.

Start with the [wiki index](index.md) for the evidence baseline and complete page map. Short workflows are in [Getting Started](Getting-Started.md). Component responsibilities are in [Architecture](Architecture.md). Requirements coverage is in [requirements traceability](requirements-traceability.md). Release evidence is in [Delivery Verification](Delivery-Verification.md). Agent operating rules are in the project-root [`SKILL.md`](../../SKILL.md).

The workflow is educational and is not investment advice.
